# Anvita AI Workers

Anvita AI is an AI coworker that does work directly in chat, like Viktor, and can turn what it
learns into governed, enterprise-grade AI Workers, like Ema.

## Apps
- [`apps/web`](apps/web) — Next.js frontend (all screens). Runs on a local demo store, or on real data against the [backend](https://github.com/glalit52/anvita-ai-worker-backend) when `NEXT_PUBLIC_API_URL` is set.
